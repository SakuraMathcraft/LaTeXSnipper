开始使用

1 · 打开插件在 Word 或 PowerPoint 顶部的 LaTeXSnipper 选项卡中选择插入公式。
2 · 写入公式在上方可视化区域输入，或在下方源码区写 LaTeX；也可以从左侧符号库选择公式。
3 · 插入文档确认字号和颜色后点击“插入”。双击已有 OLE 公式，或选中公式后点击“加载所选”，可修改后点击“更新”。
截图识别需要打开 LaTeXSnipper 桌面端，并在桌面端设置中启用自动化接口。普通公式编辑和插入可直接在 Office 插件中完成。

编辑公式

  • 可视化区与源码区：两者同步。源码含有可视化编辑器无法原样保留的写法时，上方只显示参考结果；继续在源码区编辑，或点击“用上方结果替换源码（可撤销）”。
  • 符号库与常用：左侧可搜索公式和符号，点击磁贴插入。右键点击磁贴可加入或移出“常用”；工具栏星形按钮可收藏当前公式。常用内容在升级后保留。
  • 字体与预览：工具栏的字体、字形、字号和颜色优先用于当前公式。全局颜色会同步到源码和可视化编辑区；右键可对选中部分上色、剪切、粘贴或全选，局部颜色会立即写入源码。“最终预览”按当前属性渲染，小字号会在屏幕上放大以便检查，插入仍使用选定字号；修改已有公式时沿用该公式保存的属性。
  • 快捷键：可视化区按 Shift + Enter 插入或更新。源码区按 Tab 在光标处缩进；补全列表按 Enter 接受。

设置与字体

在 LaTeXSnipper 选项卡点击“设置”。公式默认属性用于新建公式和主动执行的格式化；编辑器里临时选择的属性优先用于当前公式。导入、导出 JSON 可保存或应用当前 Word / PowerPoint 的公式默认属性。

设置作用
符号字体决定数学字母、符号及公式结构的字体方案。可选打包提供的 TeX 和 STIX2。
数字字体单独指定普通数字使用的系统字体；选“跟随符号字体”时与公式符号保持一致。
汉字字体指定公式内汉字使用的系统字体；使用与 Word 常用汉字字体一致的固定列表（等线到幼圆）。
默认字形控制数学字符的正体、斜体、粗体、花体等表现，与字体方案分别选择。“自动”保留公式原有的数学排版；源码中明确指定的局部字形优先。
字号、颜色决定新公式的默认大小和颜色。“新建时跟随文字字号”启用后优先使用光标或选区文字字号，无有效字号时使用设置中的固定值。

升级或重装会保留公式默认属性、插入方式、Word 编号布局和编辑器常用内容。导入公式预设只替换对应宿主的公式默认属性。

Word 中的常用操作

插入与编号

“插入行内公式”放在当前文字中；“插入行间公式”单独占一行；“插入带编号公式”按设置的左右位置与外框显示编号。设置中的“带编号公式默认布局”还可选择章、节编号、层级分隔符，以及是否显示章/节分隔符。

加载、转换和格式化

OLE 公式复制到另一份文档后仍可加载并独立编辑。选择普通 OLE 公式并点击“转为 MathType”，可得到 MathType 原生对象。双向转换无需安装 MathType；双击编辑转换后的对象需要 MathType。转换后不再保留插件源码与字体快照。Word 带编号公式暂不支持此转换。支持同时选择多个公式逐项转换，失败项保留原公式并继续处理其他项，结束后显示统计及具体错误。选择 MathType 公式后点击“转为 OLE”，可以用其当前 MathML 内容重新生成插件公式，支持多选和失败续跑；不会恢复转换前的 LaTeX 与字体快照。

选中插件插入的公式后，用“加载所选”修改或用“删除所选”移除。设置中的“公式插入方式”可选 OLE 对象或 Word 原生公式；“转换为 OLE / Word 原生公式”可处理已选公式。“格式化所选 / 全文”按当前默认属性整理公式。

解析正文中的 LaTeX

“解析所选 / 全文”识别完整的 $...$、\(...\)、$$...$$ 和 \[...\]。未闭合或转换失败的内容会保留原文；行间公式中的有效 \tag{...} 可作为自定义编号。

重编号与引用

“自动编号”可给未编号的行间公式添加编号；插入章/节分隔符后，后续编号会按层级更新。“重编号”重新计算全文插件公式编号。用“插入引用”创建占位符，再选择目标编号公式或其所在段落完成引用。

侧边栏保留独立的新公式草稿；加载并更新已有公式请使用编辑器窗口。

PowerPoint 中的常用操作

插件 OLE 公式复制到另一份演示文稿后仍可加载并独立编辑。“转为 MathType”将所选插件 OLE 公式转换为 MathType 原生对象。双向转换无需安装 MathType；双击编辑转换后的对象需要 MathType。转换后不再保留插件源码和字体快照。支持多选批量转换；失败项保留原公式，继续处理其他项，并显示统计及具体错误。选择 MathType 公式后点击“转为 OLE”，可以用其当前 MathML 内容重新生成插件公式，支持多选和失败续跑；不会恢复转换前的 LaTeX 与字体快照。

在文本框内把光标放在文字中间并点击“插入公式”，会得到随文字排版的 PowerPoint 原生公式，可在 PowerPoint 中继续编辑。光标不在文字中时，新公式作为居中的独立幻灯片对象插入，并按设置选择 OLE 对象或 PNG 图片。

选中插件公式后，可“加载所选”修改、“删除所选”、在 OLE 与 PNG 间转换，或用“格式化所选 / 全文”应用当前默认属性。更新与转换会尽量保留对象在幻灯片中的位置和手动缩放。

侧边栏用于新公式草稿；“加载所选”、OLE / PNG 转换和批量格式化适用于插件插入的独立对象。文本内原生公式由 PowerPoint 管理。

Get started

1 · Open the pluginUse the LaTeXSnipper tab at the top of Word or PowerPoint to insert a formula.
2 · Write the formulaType in the visual area or the LaTeX source pane, or choose a formula from the symbol library.
3 · Insert itCheck the size and color, then select Insert. Double-click an existing OLE formula, or select a formula and use Load Selected, then Update.
Screenshot recognition requires the LaTeXSnipper desktop app with the Automation API enabled in its settings. Ordinary formula editing and insertion work inside the Office plugin.

Edit formulas

  • Visual and source panes:They stay in sync. When the visual editor cannot preserve source exactly, the upper pane is a reference. Keep editing below, or choose “Replace source with result (undoable)”.
  • Library and Common:Search and click a tile to insert it. Right-click a tile to add or remove it from Common. Use the toolbar star to save the current formula. Common survives upgrades.
  • Typography and preview:Toolbar choices apply to the current formula. The formula color is synchronized with the source and visual editor. Right-click in the visual editor to color a selection, cut, paste, or select all; local colors are written to the source immediately. Final Preview enlarges small formulas on screen for inspection; insertion still uses the selected point size. Existing formulas reopen with their saved properties.
  • Keys:In the visual pane, Shift + Enter inserts or updates. In source, Tab indents at the caret and Enter accepts a completion.

Settings and fonts

Open Settings from the LaTeXSnipper tab. Default formula properties apply to new formulas and explicit Format commands. Editor choices take priority for the current formula. Import and export JSON to save or apply the current host's formula defaults.

SettingWhat it controls
Symbol fontThe font scheme for mathematical letters, symbols, and formula structures. The bundled choices are TeX and STIX2.
Number fontAn optional system font for ordinary digits. Follow Symbol Font keeps numbers with the mathematical symbols.
CJK fontA system font for Chinese characters within formulas. The fixed list contains common Chinese fonts, from DengXian to YouYuan.
Default math styleUpright, italic, bold, script, and other mathematical shapes, selected independently from the font scheme. Automatic preserves normal mathematical styling; explicit source styles take priority.
Size and colorDefaults for new formulas. Follow Text Size uses the text at the insertion point when available and falls back to the fixed size.

Upgrades and reinstalls preserve formula defaults, insertion choices, Word numbering preferences, and Common formulas. Importing a formula preset replaces only that host's formula defaults.

Common tasks in Word

Insert and number

Insert Inline places a formula within text. Insert Display gives it a separate line. Insert Numbered positions the number and enclosure according to settings. Default Numbered Formula Layout also controls chapter and section numbering, separators, and boundary visibility.

Load, convert, and format

Copied OLE formulas remain independently editable in another document. To MathType converts an unnumbered OLE formula into a native MathType object. Conversion in either direction works without MathType installed; double-click editing of native MathType objects requires MathType. The plugin source and font snapshot are not retained after conversion. You can convert multiple selected formulas; failed items remain unchanged while the rest continue, followed by a summary and the specific error. Select MathType equations and choose To OLE to generate plugin objects from their current MathML, with the same batch handling. This does not restore the original LaTeX or font snapshot.

Select a plugin formula to Load Selected or Delete Selected. Formula Insertion offers OLE objects or native Word equations. Convert to OLE / Word Equation changes selected formulas. Format Selected / All applies the current default properties.

Parse LaTeX in document text

Parse Selected / All recognizes complete $...$, \(...\), $$...$$, and \[...\] expressions. Incomplete or failed conversions leave the original text in place. A valid \tag{...} can provide a custom number for a display formula.

Renumber and reference

Auto Number numbers an unnumbered display formula. Chapter and section boundaries affect later numbers. Renumber recalculates plugin formula numbers across the document. Insert Reference creates a placeholder; select a numbered formula or its paragraph to complete it.

The side pane keeps a separate draft for a new formula. Use the editor window to update an existing one.

Common tasks in PowerPoint

Plugin OLE formulas remain independently editable after copying to another presentation. To MathType converts the selected plugin OLE formula into a native MathType object. Conversion in either direction works without MathType installed; double-click editing of native MathType objects requires MathType. The plugin source and font snapshot are not retained after conversion. Multiple selected formulas are converted individually; failed items remain unchanged while the rest continue, with a summary and the specific error. Select MathType equations and choose To OLE to generate plugin objects from their current MathML, with the same batch handling. This does not restore the original LaTeX or font snapshot.

Place the text caret inside a text box to insert a native PowerPoint equation that flows with the surrounding text and remains editable in PowerPoint. Outside text, Insert Formula adds a centered slide object using the OLE or PNG insertion setting.

Select a plugin formula to Load Selected, Delete Selected, convert between OLE and PNG, or apply Format Selected / All. Updates and conversions preserve the slide position and manual scale where possible.

The side pane holds a new formula draft. Load Selected, OLE / PNG conversion, and bulk formatting apply to standalone objects inserted by the plugin. PowerPoint manages equations within text.
