# 客户端首次使用引导方案

日期：2026-09-23
状态：方案已确认，待实现。本文描述目标行为，不代表功能已经上线。
适用范围：客户端主窗口；不涉及 Office 插件编辑器。

## 1. 目标与入口

首次进入主窗口后，通过轻量高亮引导帮助用户认识截图识别、结果、导出、快捷键和模型准备状态。复用现有 PyQt6 / QFluentWidgets 界面、配置与模型生命周期，不另建初始化流程。

主窗口“截图识别”右侧新增紧凑的“ⓘ 入门引导”入口。截图识别保持主操作视觉层级并占据剩余宽度，引导按钮按内容确定宽度，不将原按钮机械地平分。空间不足时显示图标，保留提示文字和可访问名称。点击该入口始终可以重新查看引导。

欢迎和结束使用居中卡片，中间步骤通过柔和遮罩、高亮区域和说明卡片指向真实控件。步骤指示、上一页、下一页、跳过及关闭行为保持一致；Esc 可以退出。不通过启动全屏网页或独立安装向导替代主窗口交互。

## 2. 六步内容

| 步骤 | 标题与说明 | 操作与定位 |
| --- | --- | --- |
| 1 | 欢迎使用 LaTeXSnipper / 您的快速上手向导。 | 居中欢迎卡片；开始引导、跳过 |
| 2 | 从这里开始 / 捕获、识别，再导出您的公式。 | 在同一步中依次突出截图识别、结果区和导出入口，不要求用户必须识别成功才能继续 |
| 3 | 让操作更顺手 / 设置您习惯的截图快捷键。 | 显示当前实际快捷键；修改快捷键、下一步；打开现有配置界面，保存或取消后返回本步 |
| 4 | 正在准备识别模型 / 首次使用可能需要下载模型，您可以继续浏览。 | 根据真实模型状态更新文案和 ProgressRing；查看日志，不阻塞继续 |
| 5 | 一起让它变得更好 / 如果 LaTeXSnipper 对您有帮助，欢迎支持项目。 | Star、问题反馈、交流群、赞助；全部可选，可直接下一步 |
| 6 | 开始使用吧 / 欢迎，让公式处理更简单。 | 开始使用；模型已就绪时可提供“试试截图识别” |

标题与说明接入现有国际化机制。文案保持简洁；不使用倒计时、强制赞助、强制打开网页或强制配置快捷键。

## 3. 模型状态与进度

主窗口目前通过 `start_post_show_tasks` 启动异步预热；本地模型由 `model_runtime_controller` 管理，外部模型不执行同一套本地预热。引导只读取和订阅现有状态，不重复启动模型下载或预热，不把引导关闭与模型任务取消绑定。

| 实际状态 | 第四步表现 |
| --- | --- |
| 下载 / 加载中 | 转动的 ProgressRing 和实际阶段说明；仅存在可靠下载进度事件时显示百分比，不估算或伪造进度 |
| 已就绪 | 成功图标与“识别模型已就绪”；不再显示等待提示 |
| 准备失败 | 说明未就绪，提供查看日志及现有重试 / 配置入口；仍可继续或结束引导 |
| 使用外部模型 | 展示当前配置状态与设置入口，不显示本地模型下载提示，不将“已配置”等同于连接测试成功 |
| 尚未开始或缺少依赖 | 说明实际状态并指向现有依赖 / 模型设置入口，不声称正在下载 |

最后一步默认使用“开始使用吧”，只有真实模型状态就绪时才可显示“一切就绪”。引导完成与识别能力就绪分别管理。

## 4. 首次显示、退出与重新查看

- 主窗口完成首次布局且可交互后再显示；避免遮挡启动错误或依赖配置对话框。同一时刻只存在一个引导实例。
- 完成引导后自动记录完成，以后不再自动弹出。普通版本升级不重置该状态。
- 中途跳过、关闭或按 Esc 退出时，在统一退出卡片中提供“下次不再提示”，默认不勾选；未勾选则下次启动再次显示，勾选则关闭自动显示。不要在每一页重复放置该复选框。
- 中途退出后再次自动显示，从欢迎页开始；不持久化步骤编号，以减少状态和恢复分支。
- 手动从“入门引导”入口进入，不改写既有自动显示偏好；完成、退出或重复查看都不使已经关闭的自动提示重新开启。仅自动引导的退出卡片显示“下次不再提示”。
- 关闭应用时直接结束引导，不额外弹出退出确认；未完成的自动引导保持原有偏好。
- 完成记录和自动显示偏好保存在现有用户配置中，随正常配置保存，不写入程序安装目录，不建立第二套配置文件。

## 5. 焦点与辅助操作

打开运行日志、快捷键设置或其他配置界面时，暂停遮罩及步骤输入，让现有窗口正常交互；返回主窗口后恢复相应步骤。若进入截图模式，先隐藏引导和遮罩，避免被截入画面；识别返回后的恢复行为由引导控制器统一处理。

步骤切换保持键盘焦点可见，支持 Tab 操作，窗口缩放或移动后重新计算高亮位置。目标控件暂不可见时采用可读的说明卡片或定位到当前有效入口，不出现悬空高亮。重复点击引导入口只聚焦已有引导，不叠加窗口。

## 6. 支持项目入口

- Star 打开项目主页，由用户自行操作。
- 问题反馈打开项目 Issues。
- 交流群和赞助先打开 README 的“支持本项目”区域；不自动加载远程二维码，不把三个大二维码同时放入引导。
- 链接复用现有项目地址定义；只有明确点击才打开外部浏览器。无法打开时显示简洁提示并允许继续。
- 后续若需要内嵌二维码，再单独确定资源来源与更新策略，不作为本阶段前置条件。

## 7. 实现边界

使用一个引导控制器管理步骤、显示来源、暂停恢复和退出；步骤定义描述文案、目标控件和动作；共享高亮 / 卡片组件只负责显示。模型状态与设置入口通过现有接口接入，不复制业务判断，不使用定时轮询日志文本来推导模型进度。

配置中只保留实际需要的完成状态与自动显示偏好。无需旧引导迁移、新版本强制重播、多个完成标志或重复状态存储。不要将本机依赖路径写入引导、构建配置或共享开发文档。

## 8. 分阶段实施与验收

1. **引导基础与主窗口入口：** 实现紧凑入口、六步框架、定位遮罩、键盘交互、首次显示、完成 / 退出偏好及手动重播。验证窗口缩放、重复打开、完成后重启和中途退出的不同选择。
2. **业务状态与操作接入：** 接通实际快捷键、日志、模型准备状态和支持链接。验证模型提前完成、持续下载、失败、依赖缺失、外部模型、打开设置后返回，以及引导关闭不取消后台任务。
3. **视觉与交互验收：** 检查明暗主题、中文 / 英文、不同 DPI 和窗口尺寸、焦点与截图模式；确认没有遮罩残留、重复预热、虚假百分比或未就绪却宣称就绪的文案。更新当前用户手册后再构建发布。

各阶段独立检查差异并验证当前行为；不添加只证明旧文件或旧接口不存在的墓碑测试。当前文档提交不包含功能实现，不将计划标记为已验收。
