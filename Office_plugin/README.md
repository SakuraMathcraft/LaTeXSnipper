# LaTeXSnipper Office Plugins

- [Windows](windows/README.md) contains the Word and PowerPoint add-ins, the OLE handler, and the build, test, and installer entry points.
- [macOS](macos/README.md) contains the Office.js add-in for Word and PowerPoint for Mac, its standalone local host, tests, and DMG build.
- [`shared/EditorAssets`](shared/EditorAssets) contains the formula editor, symbol and template catalogs, and bundled browser assets. [`shared/editor`](shared/editor/README.md) contains the shared editor build and unit tests. [`shared/mathjax`](shared/mathjax) contains the MathJax typography adapter.

Download the add-in for your platform from [GitHub Releases](https://github.com/SakuraMathcraft/LaTeXSnipper/releases/latest) and follow the [Office user guide](../user_manual/user_manual.md#加载项介绍与系统要求). The [formula workflows and metadata](../docs/office_plugin_formula_workflows.md) and the [Automation API](../docs/automation_api.md) describe the document and screenshot recognition interfaces.
