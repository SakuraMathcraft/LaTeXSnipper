# LaTeXSnipper Office Plugins

- [Windows](windows/README.md) contains the Word and PowerPoint add-ins, the OLE handler, and the build, test, and installer entry points.
- [`shared/EditorAssets`](shared/EditorAssets) contains the formula editor, symbol and template catalogs, and bundled browser assets. [`shared/mathjax`](shared/mathjax) contains the MathJax typography adapter.

See the [formula workflows and metadata](../docs/office_plugin_formula_workflows.md) and the [Automation API](../docs/automation_api.md) for the document and screenshot recognition interfaces.
