# Office interoperability samples

Open a copy of each document in Microsoft Office for Windows with the Windows add-in installed. Select the indicated formula, use **Load Selected**, update it, save and reopen the document. Check that the add-in can load the updated formula and that the identified document content survives.

| Document | Formula to select | Additional check |
| --- | --- | --- |
| [Word](mac-word-sample.docx) | Numbered OMML formula (1-1), from `E_0=mc^2+K` | The equation number and its cross-reference still match. |
| [PowerPoint](mac-powerpoint-sample.pptx) | PNG formula from `\sum_{k=1}^{n} k^2=\frac{n(n+1)(2n+1)}{6}\quad (n\ge 1)` | The picture keeps its position and scale. |

The samples were saved with the macOS add-in. The Word embedded object and PowerPoint shape simulate Windows OLE formulas for skip checks. To validate OLE activation and editing, use documents generated by the Windows add-in.
